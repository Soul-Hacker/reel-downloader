⚙️ One-time setup required to download videos
This tool uses RapidAPI to extract Instagram videos. You need a free API key:

1. Sign up free at rapidapi.com
2. Subscribe (free) to Instagram Downloader API (100 req/day free)
3. Copy your X-RapidAPI-Key
4. Open src/main/resources/application.properties
5. Replace YOUR_RAPIDAPI_KEY_HERE with your key
6. Restart the server: java -jar target\reel-downloader-1.0.0.jar
